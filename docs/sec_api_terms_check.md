# ตรวจเงื่อนไขการใช้ข้อมูล SEC Open API (ตรวจเมื่อ 2569-10-14)

## ตรวจซ้ำ 15 ต.ค. 2569

- [ประกาศย้ายบริการของ ก.ล.ต.](https://api-portal.sec.or.th/changes) ยืนยันว่า Developer Portal ใหม่เปิด 12 ม.ค. 2569 และพอร์ทัลเดิมยุติ 30 มิ.ย. 2569 จึงไม่ควรใช้เงื่อนไขและเพดานคำขอของระบบเดิมเป็นหลักฐานสำหรับระบบปัจจุบัน
- ลองเปิด [Agreement ของพอร์ทัลเดิม](https://api-portal.sec.or.th/Agreement) แล้วได้ 502; ค้นหาข้อตกลงฉบับเต็มของพอร์ทัลใหม่บนเว็บสาธารณะ ยังไม่พบข้อความต้นฉบับที่อ่านได้ จึง **ยังยืนยันสิทธิในการเผยแพร่ซ้ำ/การใช้เชิงพาณิชย์ไม่ได้**
- ข้อมูลกองในเว็บระบุแหล่ง SEC Open API และวันที่ข้อมูลแล้ว แต่ก่อนเปิดสาธารณะควรอ่านเงื่อนไขฉบับเต็มขณะล็อกอินพอร์ทัลใหม่ หรือขอคำตอบจาก ก.ล.ต. โดยตรงตามช่องทางในประกาศ ผู้ใช้เป็นผู้ดำเนินการเข้าบัญชี/ส่งคำถาม; ห้ามอ้างข้อตกลงเก่าว่าอนุญาตแล้ว


**สถานะ: [ยืนยันบางส่วน]** ยังไม่ได้อ่านข้อตกลงฉบับเต็มของพอร์ทัลใหม่ด้วยตัวเอง ข้อมูลด้านล่างมาจากผลค้นหาที่สรุปหน้า Agreement ของพอร์ทัลเดิม (`api-portal.sec.or.th/Agreement`) ซึ่งตอนนี้เปิดไม่ได้ (DNS ไม่พบโดเมน) เพราะ ก.ล.ต. ย้ายบริการ SEC Open API ไป Developer Portal ใหม่ในเว็บ SEC Open Data (เปิด 12 ม.ค. 2569; วันปิดพอร์ทัลเดิมในประกาศสองหน้าไม่ตรงกัน)

## สิ่งที่พบ (ถ้อยคำสรุป ไม่ใช่ข้อความต้นฉบับ)
| หัวข้อ | สิ่งที่พบ |
|---|---|
| ที่มาของข้อมูล | ข้อมูลที่เผยแพร่ผ่าน SEC API ประกอบจากข้อมูลของ ก.ล.ต. และข้อมูลที่ได้รับจากแหล่งอื่น และ "สามารถเผยแพร่ได้" |
| ความรับผิดชอบ | ผู้ใช้รับผิดชอบการนำข้อมูลไปใช้ ก.ล.ต. ไม่รับรองความสมบูรณ์/ถูกต้อง/ความล่าช้า ไม่รับผิดต่อความเสียหายจากการใช้ |
| การรบกวนระบบ | ห้ามส่งโค้ดอันตราย/โจมตีเครือข่าย ถ้าเกิดความเสียหายผู้ใช้ต้องชดใช้ |
| การเปลี่ยนแปลง | ก.ล.ต. แก้ข้อตกลง เปลี่ยนข้อมูล จำกัดการใช้ หรือยุติบริการได้โดยไม่ต้องแจ้งเหตุผล |
| กฎหมาย | กฎหมายไทย ศาลไทย |
| Rate limit (พอร์ทัลเดิม) | ทุก API 3,000 คำขอ/300 วินาที เว้น 10 ms ระหว่างคำขอถ้าตอบเร็ว และรอเมื่อได้ HTTP 421 ขอเพิ่มได้ที่ repcenter@sec.or.th |
| นโยบายเว็บไซต์ ก.ล.ต. (`sec.or.th/EN/Pages/Footer/WebsitePolicy.aspx` อ่านต้นฉบับแล้ว) | ใช้/พิมพ์/ดาวน์โหลดเนื้อหาเป็นข้อมูลทั่วไปได้ โดย **ห้ามแก้ไขสาระให้ผู้อ่านเข้าใจผิด**; ใช้โลโก้ ก.ล.ต. ต้องขออนุญาตเป็นลายลักษณ์อักษร; เนื้อหาไม่ถือเป็นคำแนะนำการลงทุน (นโยบายนี้เป็นของเว็บไซต์ ไม่ใช่ของ API โดยตรง) |

## ที่ยังไม่พบ / ไม่ทราบ
- เงื่อนไขการอ้างแหล่งที่มา (attribution) และการใช้เชิงพาณิชย์ ไม่พบในสรุปที่เข้าถึง
- ข้อตกลงของพอร์ทัลใหม่อาจต่างจากฉบับเดิม
- Rate limit ของพอร์ทัลใหม่ ยังไม่ทราบ (รอบดึงของเราใช้ ~1–2 คำขอ/วินาที ต่ำกว่าเพดานเดิมมาก และไม่เคยได้ 429)

## แนวปฏิบัติที่ควรใช้ถ้าทำเว็บสาธารณะ
1. แสดงที่มา "ข้อมูลจาก ก.ล.ต. (SEC Open API)" และวันที่ข้อมูล (as of) ทุกหน้า
2. ไม่แก้ค่าข้อมูลให้ผู้อ่านเข้าใจผิด (แสดงค่าตามต้นทาง ค่าว่างแสดงว่าว่าง) แยก "ข้อมูลจาก ก.ล.ต." ออกจาก "ค่าที่เราคำนวณ"
3. ไม่ใช้โลโก้ ก.ล.ต.; มี disclaimer ว่าไม่ใช่คำแนะนำการลงทุนและไม่รับรองความถูกต้อง
4. เก็บ API key ฝั่งงานดึงข้อมูลเท่านั้น เว็บแสดงไฟล์ snapshot ไม่ proxy คำขอสดไปที่ API
5. ออกแบบให้ทนต่อการที่ ก.ล.ต. เปลี่ยนหรือยุติ API (เก็บ snapshot ไว้, ไม่ผูกกับ endpoint เดียว)

## สิ่งที่ผู้ใช้ควรทำก่อนเปิดเว็บสาธารณะ
- ล็อกอินพอร์ทัลใหม่ (SEC Open Data) แล้วอ่านข้อตกลงฉบับเต็มด้วยตัวเอง
- ถ้าจะเผยแพร่ซ้ำหรือใช้เชิงพาณิชย์ ให้อีเมลถาม repcenter@sec.or.th ตรงๆ และเก็บคำตอบไว้
