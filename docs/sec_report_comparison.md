# เทียบการจัดประเภท RMF กับรายงาน ก.ล.ต. (SSF_TH.xls)

แหล่ง: รายงาน "รายละเอียดกองทุนรวม SSF/RMF/LTF จำแนกรายกองทุน" ของ ก.ล.ต. (ไฟล์ `ref/SSF_TH.xls`, แสดง AS OF 31/7/2569; ผู้ใช้ดาวน์โหลดเองเมื่อ 2569-10-13)
สคริปต์: `scripts/11_compare_sec_ssf_report.py` -> `data/sec_report_comparison.csv` (ไม่ขึ้น GitHub)

## ผล
- รายงานมี RMF 424 แถว (SSF 386, SSF listed 19; LTF ไม่มีข้อมูล)
- RMF ของเรา 437 class (389 โครงการ) **ตรงกับตาราง RMF ของ ก.ล.ต. 423 class (97%)**: ชื่อย่อตรง 386 + ชื่อย่อแบบหลวม 8 (เช่น TFPRMF -> TFPRMF-PVD) + ชื่อกองเต็มตรง 29 (13 โครงการที่ช่องชื่อย่อในรายงานเป็นรหัสสุ่ม เช่น `1fA9BCDazxKL`)
- **ไม่พบ 14 class (14 โครงการ)**: 13 โครงการจดทะเบียน/เปิด IPO ปี 2569 (M…_2569) ซึ่งน่าจะเกินรอบรายงาน และ K-SELECTRMF (M0061_2544, "เค ซีเล็คท์ หุ้นทุนเพื่อการเลี้ยงชีพ") ซึ่งไม่มีชื่อนี้ในรายงานเลย (รายงานมีเฉพาะ K-GSELECTRMF ซึ่งเป็นกองอื่น) ควรตรวจกับ บลจ. กสิกรไทย
- ไม่มี class ใดของเราไปปรากฏในตาราง SSF แทน = **ไม่พบกรณีจัดผิดประเภท**
- ThaiESG (58) และ ThaiESGX (123) ไม่อยู่ในไฟล์นี้ จึงเทียบไม่ได้

## ข้อจำกัด
- จับคู่ด้วยชื่อย่อที่ normalize แล้ว เพราะเลขที่จดทะเบียนในรายงาน (003/2545) ไม่ตรงรูปแบบ proj_id (M0004_2556)
- การจับคู่ระดับชื่อเต็มเป็นการเทียบข้อความ ไม่ใช่เลขทะเบียน

## ผลต่อสถานะข้อมูล
- RMF 423 class: มีหลักฐานจาก ก.ล.ต. ยืนยันว่าเป็นกอง RMF ระดับโครงการ (ความเชื่อมั่นเพิ่มจาก "medium" ได้ แต่ตั้ง `verified_status = sec_report_rmf_2569-07-31` แล้ว (คอลัมน์ confidence คงเดิม))
- 14 class ที่เหลือ คงสถานะเดิม (จัดจากชื่อ ยังไม่ยืนยัน)

## ตรวจ 14 class ที่ไม่พบ (2569-10-14, จาก `data/profiles_raw.json` ฟิลด์ `regis_date`/`init_date`)
รายงานแสดงข้อมูล ณ **31 ก.ค. 2569** ส่วนกองเหล่านี้ (วันที่ใน API เป็น ค.ศ.):

| กลุ่ม | โครงการ | วันที่จดทะเบียน (regis_date) | สรุป |
|---|---|---|---|
| จดทะเบียนแล้ว 9 | TLUSGOVRMF, K-GNEXTRMF, DAOL-GTECHRMF, TLWORLDHDRMF, B-WEALTH C/M/B/D/G RMF | 4 ก.ย. – 2 ต.ค. 2569 | **หลังรอบรายงานทั้งหมด** จึงไม่อยู่ในรายงานเป็นเรื่องปกติ |
| IPO 4 | SCBRMAXJ, SCBRMSEMI, SCBRMKEQ, TLWORLDBONDRMF | ยังไม่จดทะเบียน (มีแต่ init_date 7 พ.ค. – 2 ต.ค. 2569) | ยังไม่เป็นกองที่จดทะเบียน จึงไม่อยู่ในรายงาน |
| ผิดปกติ 1 | K-SELECTRMF (M0061_2544) | 19 ธ.ค. 2544, สถานะ Registered, มี NAV 8 ต.ค. 2569 | **เป็นกองเก่าที่ยังเปิดอยู่ แต่ไม่อยู่ในรายงาน** ต้องตรวจเพิ่ม |

- 13 โครงการปี 2569 อธิบายได้ด้วยวันที่ จึงไม่ใช่ข้อบกพร่องของการจัดประเภท แต่ยังไม่มีหลักฐานจากรายงานว่าเป็น RMF (ชื่อลงท้าย "เพื่อการเลี้ยงชีพ") คง `unverified` จนกว่าจะมีรายงานรอบใหม่
- K-SELECTRMF ชื่อกอง "เค ซีเล็คท์ หุ้นทุนเพื่อการเลี้ยงชีพ" ลงท้ายด้วย RMF ชัดเจน แต่ยังไม่มีเอกสารยืนยัน ถือเป็นกรณีเดียวที่ต้องตามต่อ
