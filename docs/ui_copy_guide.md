# แนวทางถ้อยคำและหน้าตาของระบบ (ปรับปรุง 2569-10-15)


เหตุผล: ข้อความเดิมปนภาษาพูด (เช่น "คุณ" "ลอง" "ใส่เท่าที่มี" "ปรับให้แม่นขึ้น") สัญลักษณ์ตกแต่ง (▲ ⚙ ☀ 💡 →) และชื่อภาษาอังกฤษ ทำให้ดูไม่เหมือนระบบของสถาบันการเงิน จึงปรับให้สอดคล้องกับถ้อยคำที่หน่วยงานและผู้ให้บริการที่ทำเครื่องมือด้านนี้ใช้จริง

## แหล่งที่ใช้เทียบถ้อยคำ (อ่านจากหน้าจริงเมื่อ 2569-10-15)
- [กองทุนลดหย่อนภาษี (insight-fund.sec.or.th ของ ก.ล.ต.)](https://insight-fund.sec.or.th/mutual-fund-info/tax-saving-fund) — ภาษากลาง ไม่ใช้สรรพนามบุรุษที่ 2 ใช้ "ผู้ลงทุน" และ "สิทธิลดหย่อนภาษี" "ไม่ควรลงทุนเกินสิทธิของตน"
- [เครื่องมือคำนวณภาษีของ Finnomena](https://www.finnomena.com/tax/calculator) — ชื่อขั้นตอน "ขั้นตอนที่ 1 รายได้" และข้อความหมายเหตุ "เป็นการคำนวณเบื้องต้นเท่านั้น ... ไม่รับรองความถูกต้อง ... ผู้ลงทุนควรศึกษาหรือปรึกษาผู้เชี่ยวชาญด้านภาษีก่อนการลงทุน"
- [บทความของ บลจ.ไทยพาณิชย์](https://www.scbam.com/th/knowledge/money-diy/money-diy-28092026) — รูปประโยคเงื่อนไข "ใช้สิทธิลดหย่อนภาษีได้ตามจำนวนที่จ่ายจริง สูงสุดไม่เกินร้อยละ 30 ของเงินได้พึงประเมิน" "ถือครอง 5 ปีเต็มนับจากวันลงทุน"
- คู่มือการกรอกแบบ ภ.ง.ด.90 ของกรมสรรพากร — ศัพท์ทางการ: เงินได้พึงประเมิน ค่าลดหย่อน เงินได้สุทธิ ภาษีที่ต้องชำระ ภาษีหัก ณ ที่จ่าย

## หลักการเขียน
1. **ไม่ใช้สรรพนาม** "คุณ" "ฉัน" "ของฉัน" "เรา" ใช้ "ผู้ใช้" เมื่อจำเป็น หรือเขียนเป็นประโยคกลาง (เช่น "ระบุเฉพาะรายการที่มี")
2. **ภาษากึ่งทางการ** ไม่ใช้ภาษาพูดหรือคำสั่งเชิงเป็นกันเอง ("ลอง" "ใส่" "เติม" "ข้ามได้เลย") ใช้ "ระบุ" "กำหนด" "สามารถ...ได้"
3. **คำปฏิเสธเชิงประกาศ** ใช้ "มิใช่" "มิได้" ในข้อสงวนสิทธิ์ตามแบบของ ก.ล.ต. ("ผลการดำเนินงานในอดีตมิได้เป็นสิ่งยืนยัน...")
4. **ไม่ใส่คำที่รับประกันเกินจริง** เช่น "ภาษีที่ประหยัดได้จริง" ใช้ "ภาษีที่ประหยัดได้ (ประมาณการ)"
5. **ไม่ใช้สัญลักษณ์ตกแต่ง** แทนด้วยตัวอักษร: ▲ → "หมายเหตุ", ⚙ → "ปรับสมมติฐาน", ✓ → "ตรวจสอบแล้ว", → ระหว่างค่า → "เป็น"/"ถึง"
6. **ไม่โชว์รหัสภายใน** (เช่น รหัสธงข้อมูล `fee_ter_zero`) แปลงเป็นข้อความไทยที่ `web/src/dq.ts` (ตารางรหัสกฎภาษีของรุ่นเดิมอยู่ใน `archive/tax-planner-ui/labels.ts`)
7. **ใช้ชื่อไทยเป็นหลัก** ชื่อระบบ "ข้อมูลกองทุนรวมไทย" (Thai Mutual Fund Data) ส่วนหัวข้อหน้าใช้ภาษาอังกฤษ
8. ไม่แนะนำหรือจัดอันดับกองทุน (กรอบ compliance เดิมของโปรเจกต์)

## ชื่อเมนูและคำศัพท์
| เดิม | ใหม่ |
|---|---|
| ภาพรวม | หน้าแรก |
| เงินรับ-จ่าย | ข้อมูลเงินได้ |
| ผลภาษี | ผลการคำนวณภาษี |
| สำรวจกองทุน | ข้อมูลกองทุนรวม |
| เกี่ยวกับ/ข้อจำกัด | แหล่งข้อมูลและข้อจำกัด |
| แผนของฉัน / ตามแผน | จำนวนเงินลงทุนที่กำหนด |
| ปรับให้แม่นขึ้น | ข้อมูลเพิ่มเติม (ไม่บังคับ) |
| ขั้นภาษีส่วนเพิ่ม | อัตราภาษีส่วนเพิ่ม |
| ที่เหลือ | คงเหลือ |
| เพดาน (ในประโยคอธิบาย) | วงเงินสูงสุด / ไม่เกิน |
| ยังไม่ได้ตอบ | ยังไม่ได้ระบุ |

## ด้านหน้าตา
- โหมดสว่างเป็นค่าเริ่มต้น (โหมดมืดเลือกเองได้และจำเฉพาะเมื่อผู้ใช้เลือก) เดิมตามค่าระบบของเครื่องและจำค่านั้นไว้ทำให้เปิดเป็นโหมดมืดโดยไม่ได้เลือก
- แถบหัวหน้าแรกเป็นพื้นเรียบ ไม่มีแสงฟุ้งตกแต่ง
- ธง/หมายเหตุข้อมูลแสดงเป็นป้ายข้อความ "หมายเหตุ" แทนสัญลักษณ์

## ข้อควรรู้
- ไม่มีเทสต์อัตโนมัติสำหรับถ้อยคำหน้าเว็บ ผู้ที่แก้ข้อความควรตรวจตามหลักด้านบน และใช้ `python scripts/ui_strings_extract.py` ดึงข้อความทั้งหมดมารีวิว
