# แหล่งทางการสำหรับตรวจประเภทกองทุน

ตรวจเมื่อ 9 ตุลาคม 2569: พบหน้า [SEC Capital Market Report PP28](https://market.sec.or.th/public/idisc/th/CapitalMarketReport/PP28) ซึ่งแสดงรายงาน “รายละเอียดกองทุนรวมเพื่อการออม (SSF), กองทุนรวมเพื่อการเลี้ยงชีพ (RMF), กองทุนรวมหุ้นระยะยาว (LTF) ที่จดทะเบียนกับสำนักงาน จำแนกรายกองทุน” โดยหน้าเว็บระบุงวด 8 ตุลาคม 2569

[data.go.th: รายละเอียดกองทุนรวมที่จดทะเบียนกับสำนักงาน](https://data.go.th/en/dataset/dataset_11_0001) ระบุสำนักงาน ก.ล.ต. เป็นเจ้าของข้อมูล มีทรัพยากรแยกสำหรับ RMF และอ้างหน้า PP28 เป็นแหล่งที่มา ข้อมูลบน data.go.th ระบุวันที่ปรับปรุงชุดข้อมูล 30 มิถุนายน 2569 จึงอาจเก่ากว่าข้อมูล profiles ที่ดึง 8 ตุลาคม 2569

**สถานะ:** พบแหล่งทางการแล้ว แต่ยังไม่ได้ดาวน์โหลดและจับคู่รายการกับ `data/fund_class_types.csv` จึงยังคง `confidence=medium` และ `verified_status=unverified` สำหรับ RMF และ ThaiESGX ตามเดิม หน้า PP28 ครอบคลุม RMF/SSF/LTF โดยชื่อรายงานไม่ระบุ ThaiESGX จึงต้องหาแหล่งยืนยัน ThaiESGX แยกต่างหาก

การเทียบในขั้นถัดไปควรใช้ชื่อย่อกองทุนและรหัสทะเบียน ร่วมกับชื่อ class เมื่อมี ไม่ควรถือว่าจำนวน “กอง” ในรายงานเท่ากับจำนวน class ใน SEC Open API โดยตรง
